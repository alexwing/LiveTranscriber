# Dependencias del sidecar de voz (tts_server.py). Van en un venv APARTE del
# de los otros sidecars, y no es capricho: asr_server.py exige
# transformers>=5.13 (es donde vive AutoModelForRNNT) y chatterbox-tts esta
# probado con 4.57.x. Los dos conjuntos no caben en el mismo entorno.
#
# Lo monta `install.ps1 -WithVoice` en `.venv-tts`. A mano seria:
#
#   python -m venv .venv-tts
#   .venv-tts\Scripts\pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
#   .venv-tts\Scripts\pip install -r sidecar\requirements-tts.txt
#
# chatterbox-tts va con --no-deps A PROPOSITO: pina torch==2.6 y
# transformers==5.2.0 exactos que no hacen falta (probado con torch 2.11 y
# transformers 4.57); sin --no-deps, pip destrozaria el venv reinstalando
# torch sin CUDA. Sus dependencias reales van listadas debajo.
#
#   .venv-tts\Scripts\pip install --no-deps chatterbox-tts
